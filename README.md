# 韩国购物清单

在线访问：<https://yumibazi.github.io/oliveyoung-shopping-list/>

Olive Young、DAISO 和 NYUNYU 共用一个界面，各有购物清单和备选栏。

## 备选资料来源

- DAISO：官方商城首页的“旅行 BEST”精选。卡片使用官方商品图；价格、库存与店内款式会变动。
- NYUNYU：[《【nyunyu明洞】免税いくらから？支払い方法、バッグ、ピアス、帽子の値段も調査！》](https://zizitabi.com/entry/nyunyu-seoul) 的首尔旅行实拍。文中数据为 2024 年 4 月调研，所以网站明确标为“历史参考”或“到店选款”。

## 使用同步

1. 点击页面上方「登录同步」，用邮箱注册并完成确认邮件验证。
2. 手机和电脑登录同一个购物清单账号。此账号独立于 Supabase 管理员账号。
3. 在保存着旧记录的浏览器，登录后选择「我的同步账号 → 导入此设备旧清单」。这会替换账号的完整清单，操作前有确认，原始本地记录保留。
4. 新增、删除、排序、备注、已购状态会自动同步。在线前台页面约每 5 秒检查更新；填写表单或拖动时延后载入。

未登录时仍只保存到当前浏览器。离线修改保存在当前账号的本地待同步记录，联网后自动重试。两台设备同时修改发生版本冲突时，需要明确选择云端版本或此设备版本，不自动覆盖。看到「已同步」后再关闭页面最稳妥。

## 部署

静态文件：index.html、sync.js，发布到 GitHub Pages。
Supabase 项目：jycsvwtynqkyhourttdu。sync.js 中仅包含公开 publishable key，不包含管理员密钥。

- 在 SQL Editor 执行 `supabase/setup.sql`，启用账号隔离和原子版本检查。
- Authentication → URL Configuration → Site URL 设置为网站完整网址。
- 邮箱注册需启用 Email provider，默认要求确认邮箱。面向其他访客公开注册时，应根据 Supabase 邮件服务限制配置自己的 SMTP。
- `shopping_sync` 使用 RLS，每人只能访问自己的记录。单份完整清单上限 8 MiB；浏览器本地缓存容量也会限制上传图片数量。
- 免费服务的连接情况和额度以 Supabase 当前政策为准。

测试使用独立浏览器模拟服务响应，覆盖两设备同步、离线队列、账号隔离、备注、新增删除、冲突和旧数据迁移。生产接口另外核查匿名读写被拒绝；实际邮箱投递需使用者完成首次注册确认。
